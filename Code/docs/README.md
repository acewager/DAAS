# Documentation

The full product/architecture specification for this project lives in the
project's knowledge base (numbered documents 01A through 22, e.g.
`02_System_Architecture.md`, `07_REST_API.md`, `16_AI_AGENT_INSTRUCTIONS.md`).

This `docs/` folder is reserved for documentation that ships with the
repository itself (e.g. generated API schemas, runbooks) as those are
produced during later milestones. Until then, treat the numbered
specification documents as the source of truth.
